# 未收集昆虫刷新 Mod：功能介绍与刷新规则

[返回仓库首页](../README.md) · [查看独立安装教程](INSTALL_UNCOLLECTED_INSECT_SPAWNER.zh-CN.md)

- 当前版本：`v1.0.10`
- 技术名称：`UncollectedBeetleSpawner`

## 这个 Mod 做什么

本 Mod 专门修改丛林探索地图中的甲虫和蝴蝶刷新，帮助玩家补齐昆虫图鉴。它不提供甲虫大作战的招式预测；需要对战预测时，请使用独立的[甲虫大作战预测 Mod](BEETLE_BATTLE_PREDICTOR.zh-CN.md)。

## 甲虫刷新规则

- 甲虫刷新点的原版候选池中存在未收集种类时，只从这些未收集种类中选择。
- 多个未收集种类之间保留游戏原有的相对刷新权重。
- 甲虫刷新点会把原版的“不刷新”结果替换为池内甲虫，因此刷新率为 100%。
- 当前候选池全部收集后，种类选择恢复原版规则；甲虫刷新点仍保持 100% 刷新。

## 蝴蝶刷新规则

- 当前蝴蝶候选池存在未收集种类时，只刷新未收集蝴蝶，并把候选池中的“不刷新”结果替换为未收集蝴蝶。
- 当前候选池全部收集后，完整恢复游戏原版逻辑，包括原版“不刷新”的概率。
- 对于森林中的固定蝴蝶点，如果该蝴蝶尚未收集，Mod 可以恢复已经被标记为捕获或移除的刷新状态。
- 固定蝴蝶仍遵守游戏原有的地图、剧情和天气条件，Mod 不会把其他区域的蝴蝶强行加入当前区域。

例如，塞塔森林独木桥附近的英雄翠凤蝶原本只允许在晴天或雾天出现。v1.0.10 会处理其已捕获状态，但不会绕过这个天气限制。

## 收集状态判断

Mod 会使用昆虫图鉴、丛林存档、甲虫战斗存档和物品记录综合判断是否已经收集，并把刷新用的内部编号转换成图鉴物品编号，避免把已收集昆虫误判为未收集。

## 安全回退

- 不修改存档内容。
- 不扩大当前刷新点的原版物种池。
- 如果游戏更新导致接口读取失败，会放弃本次过滤并恢复游戏原逻辑，同时在 BepInEx 日志中记录警告。

## 开发构建

构建时需要游戏已经生成的 `BepInEx\interop` 程序集：

```powershell
.\build-uncollected-beetles.ps1 -GameDir '你的游戏目录'
```
